# Flutter

Flutter byl vybrán pro tvorbu mobilní aplikace, protože umožňuje spolehlivě generovat nativní uživatelské rozhraní na různých zařízeních. Díky vlastnímu renderovacímu enginu je zajištěna konzistence vzhledu a chování aplikace, což přispívá k lepší přístupnosti a jednotnému vizuálnímu stylu napříč mobilními zařízeními.

# NestJS

NestJS byl vybrán pro implementaci backendu, protože poskytuje strukturovaný rámec pro organizaci serverové logiky a bezpečné zpracování požadavků. Funkce autentizace, autorizace a synchronizace dat mohou být díky modulární architektuře systematicky rozděleny a spravovány, což minimalizuje riziko nekonzistentních dat mezi uživateli.

# PostgreSQL

PostgreSQL byl vybrán jako hlavní databázový systém, protože umožňuje bezpečně ukládat relačně strukturovaná data, například informace o uživatelích, jejich pokroku, přátelích a žebříčcích. Transakční zpracování a podpora relací zajišťují konzistenci a integritu dat při aktualizacích a synchronizacích mezi uživateli.

# SQLite

SQLite byla vybrána jako lokální databáze v mobilní aplikaci, aby byla umožněna práce v offline režimu. Data o uložených verších, naplánovaných opakováních a pokroku jsou dočasně uchovávána na zařízení a při obnovení připojení jsou synchronizována s hlavní databází, čímž je zajištěna kontinuita učení uživatele.
